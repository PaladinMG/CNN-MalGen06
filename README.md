# Accuracy-first tissue segmentation

This project predicts six mutually exclusive tissue probabilities at every
native-resolution pixel:

| ID | Class |
|---:|---|
| 0 | Bone |
| 1 | Fibrocartilage |
| 2 | Cartilage |
| 3 | Muscle |
| 4 | Marrow |
| 5 | Background |

The current architecture is intended for an NVIDIA RTX 4000 Ada-class GPU. Old
`TinyFeatureUNet` checkpoints are not compatible and must be retrained.

## Model design

- A pretrained ResNet-50 encodes a native-resolution 512×512 local crop.
- A pretrained ResNet-18 encodes the corresponding 2048×2048 context field
  after it is downsampled to 512×512.
- The nine requested derivative maps use a separate learned feature stem:
  Laplacian, Gaussian-weighted local deviation, gradient magnitude, structure
  tensor eigenvalues/coherence, and Hessian determinant/eigenvalues.
- Training-set BatchNorm statistics replace per-tile feature normalization,
  eliminating a major source of inference seams.
- A bilinear residual decoder avoids transposed-convolution checkerboards.
- A five-class coarse head treats Fibrocartilage and Muscle as one parent
  region. A conditional child head divides that probability into mutually
  exclusive Fibrocartilage and Muscle probabilities.
- A context-based Muscle-presence head supplies an object-like regional prior.
- A dedicated Bone–Fibrocartilage boundary head improves localization of the
  interface used for area measurement.
- Inference uses native-resolution overlapping tiles and center-weighted
  blending.

The final six probabilities sum to one. Muscle pixels count toward the combined
Fibrocartilage-or-Muscle target during coarse training, but Muscle and
Fibrocartilage remain separate in final output and area calculations.

## Data

Per-pixel masks are required:

```text
dataset/
  images/
    specimen_001.tif
    specimen_002.tif
  masks/
    specimen_001.png
    specimen_002.png
```

Masks are single-channel PNGs with IDs `0` through `5`; dimensions and stems
must match the source image. Source images are never globally resized.

Training deliberately samples:

- Bone–Fibrocartilage boundary crops
- Crops centered on a randomly selected foreground class
- Unbiased random crops

The local crop and its 1:4 context field receive identical geometric and color
augmentation. For final experiments, provide a validation directory split by
patient or specimen:

```text
train_dataset/images + masks
validation_dataset/images + masks
```

## Installation

Create a virtual environment and install a CUDA-enabled PyTorch build using the
command generated by the official PyTorch installer for the cluster's CUDA
version. Then install the remaining requirements:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

The first pretrained run downloads ResNet-50 and ResNet-18 weights. On an
offline compute node, download/cache them on a login node first or train with
`--no-pretrained` (not recommended for this dataset size).

Verify Torch/Torchvision compatibility and the complete hierarchical
forward/backward path before training:

```bash
python smoke_test.py --device cuda
```

For a lower-cost import/forward check, add `--forward-only`.

## GPU training

A strong starting point for a 20 GB RTX 4000 Ada is:

```bash
python train.py \
  --data /data/tissue/train \
  --val-data /data/tissue/validation \
  --device cuda \
  --crop-size 512 \
  --context-scale 4 \
  --batch-size 4 \
  --epochs 80 \
  --workers 4 \
  --output best_model.pt \
  --last-output last_model.pt
```

If that fits comfortably, try batch size 6 or 8. If it does not, use batch size
2 with `--accumulation-steps 2`; this retains an effective batch size of four.
CUDA automatic mixed precision is enabled by default. Use `--no-amp` only for
diagnosis or a carefully measured precision comparison.

If the source images fit in VRAM after leaving room for the model and its
activations, cache them for repeated epochs:

```bash
python train.py ... \
  --cache-training-images \
  --cache-vram-reserve-gb 10
```

This keeps the source RGB images as `uint8`, constructs the 1:4 context
pyramid only once, reuses precomputed boundary sampling maps, and batches
cached samples directly in channels-last CUDA memory. Cached mode uses zero
DataLoader workers because CUDA tensors cannot safely be shared by worker
processes.

The nine Laplace/deviation/gradient/structure-tensor/Hessian maps can also be
calculated once per source image:

```bash
python train.py ... \
  --cache-training-images \
  --cache-handcrafted-features \
  --cache-feature-tile-size 1024 \
  --cache-vram-reserve-gb 10
```

The program prints a VRAM estimate before allocating the cache. Feature maps
are stored as FP16 and require approximately 18 bytes per source pixel, in
addition to about 3 bytes for RGB and 0.19 bytes for the 1:4 RGB pyramid.
`--cache-feature-tile-size` controls temporary memory during construction, not
the final cache size. Lower it if cache construction itself runs out of VRAM.

Feature caching is optional because it changes one augmentation detail:
geometric transformations remain exactly aligned, but the cached structural
maps describe the original image while brightness, contrast, saturation, and
gamma jitter affect only RGB. This can act as useful stain-invariant
regularization, but compare validation area error both with and without
`--cache-handcrafted-features` before choosing it for the final model. Image
and context caching alone does not make this tradeoff.

Resume an interrupted run:

```bash
python train.py ... --resume last_model.pt
```

The encoder learning rate defaults to `3e-5`, while new decoder and task heads
use `3e-4`. The objective combines hierarchical cross-entropy, conditional
Muscle loss, six-class Dice, Bone–Fibrocartilage boundary loss, and regional
Muscle-presence loss. Validation reports class IoU and boundary F1.

Optional six-class weights follow the table order:

```bash
python train.py ... --class-weights 1 2 2 2 1 0.3
```

Calculate weights from training-mask pixel counts; do not copy the example
blindly.

## Native-resolution prediction

```bash
python predict.py \
  --image specimen.tif \
  --checkpoint best_model.pt \
  --output-dir prediction \
  --device cuda \
  --tile-size 512 \
  --overlap 128 \
  --batch-size 2
```

For higher-context inference, try `--tile-size 768 --overlap 192` or
`--tile-size 1024 --overlap 256` after measuring VRAM. Tile size must be a
multiple of 32. Larger inference tiles do not replace training at an adequate
native crop size.

Outputs:

- `class_ids.png`
- `color_mask.png`
- Six grayscale class-probability PNGs
- `bone_fibro_boundary.png`
- `probabilities.npy`, shape `[6, original_height, original_width]`
- `classes.txt`

Load the probability volume without placing it entirely in RAM:

```python
import numpy as np

probabilities = np.load("prediction/probabilities.npy", mmap_mode="r")
```

Use `--no-save-probabilities` if only PNG outputs are needed. Stitching still
uses a temporary disk-backed float32 array. Allow roughly 28 temporary bytes per
source pixel for six probabilities, the boundary map, and blending weights.

## Area quantification

Supply the calibrated physical pixel dimensions from the acquisition metadata:

```bash
python quantify.py \
  --prediction-dir prediction \
  --pixel-width-um 0.50 \
  --pixel-height-um 0.50
```

`area_summary.csv` reports hard-mask and probability-weighted areas in mm².
Validate both against expert specimen-level areas. Do not apply erosion,
dilation, opening, or closing unless its class-specific area bias has been
measured.

## SLURM

The supplied jobs request one GPU, eight CPU cores, and 20 GB system RAM.
Partition names and limits vary by cluster; edit `#SBATCH --partition=gpu`,
memory, and wall time as needed.

Submit training:

```bash
sbatch --export=ALL,\
DATA=/data/tissue/train,\
VAL_DATA=/data/tissue/validation,\
VENV=/work/project/.venv,\
OUTPUT=/work/checkpoints/best_model.pt,\
LAST_OUTPUT=/work/checkpoints/last_model.pt \
slurm_train.sbatch
```

Resume through SLURM:

```bash
sbatch --export=ALL,\
DATA=/data/tissue/train,\
VAL_DATA=/data/tissue/validation,\
VENV=/work/project/.venv,\
RESUME=/work/checkpoints/last_model.pt \
slurm_train.sbatch
```

Submit prediction:

```bash
sbatch --export=ALL,\
IMAGE=/data/specimen.tif,\
CHECKPOINT=/work/checkpoints/best_model.pt,\
OUTPUT_DIR=/work/results/specimen,\
VENV=/work/project/.venv \
slurm_predict.sbatch
```

Schedule prediction only after training succeeds:

```bash
TRAIN_JOB=$(sbatch --parsable --export=ALL,DATA=/data/tissue/train,\
VAL_DATA=/data/tissue/validation,VENV=/work/project/.venv slurm_train.sbatch)

sbatch --dependency=afterok:${TRAIN_JOB} --export=ALL,\
IMAGE=/data/specimen.tif,CHECKPOINT=best_model.pt,\
OUTPUT_DIR=prediction,VENV=/work/project/.venv slurm_predict.sbatch
```

Set `MODULES="cuda/12.4"` if the cluster requires an environment module. Use
`EXTRA_ARGS` for additional command-line options, for example:

```bash
sbatch --export=ALL,DATA=/data/tissue/train,VENV=/work/project/.venv,\
EXTRA_ARGS="--accumulation-steps 2 --class-weights 1 2 2 3 1 0.3" \
slurm_train.sbatch
```

The SLURM wrapper also accepts cache settings directly:

```bash
sbatch --export=ALL,DATA=/data/tissue/train,VENV=/work/project/.venv,\
CACHE_TRAINING_IMAGES=1,CACHE_HANDCRAFTED_FEATURES=1,\
CACHE_VRAM_RESERVE_GB=10 \
slurm_train.sbatch
```

## Accuracy notes

- Validate by patient/specimen, not randomly related sections.
- Measure per-class area error and boundary error in addition to mIoU.
- Retain native pixel spacing and acquisition magnification metadata.
- Inspect the probability maps rather than judging only the hard color mask.
- The regional Muscle prior supplies context and consistency, but it is not a
  full instance-segmentation system. Explicit porosity/closed-loop features
  require a validated transparent-structure mask and can later be concatenated
  with the regional head without changing the final six-class area definition.
